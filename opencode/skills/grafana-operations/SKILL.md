# Grafana Operations

## Scope boundary

Use this skill to query live Grafana data and investigate operational conditions during incidents. Use `grafana-development` to build and author dashboard artifacts.

Start with datasource discovery and focused read-only queries. Validate dashboard and alert queries before saving. Dashboard, alert, routing, contact-point, and annotation writes require approval, verification, and rollback.
